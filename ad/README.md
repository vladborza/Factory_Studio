# Factory Studio product ad

42-second silent, animated browser ad. Open `index.html` in Chrome or Edge and select Play ad. Full screen is available. It runs offline with the included assets folder. WebGL is required for 3D.

The standalone `Factory-Studio-Ad.html` one directory above contains the same ad with all scripts embedded and can be shared as a single file. This is an animated HTML ad, not an MP4.

Creative sequence: production constraint; 2D process model; camera zoom into assembly; blend to the 3D workcell; operators and automatic operations; illustrated progression through preparation, assembly, test and completed products; simulated proof; invitation to a client pilot and product link.

3D is a product vision, not a released capability. Animation is illustrative and time-compressed, not event-log playback, engineered material handling, safety validation or a measured production run.

The 19.0% claim comes from actual Factory Studio engine runs on a synthetic reference case: 318.3333 versus 378.7 mean good units in 8 hours, 30 replications each. 95% Student-t intervals for the means are [317.91346,318.75321] and [378.34440,379.05560]. These are sampling uncertainty under model assumptions, not client performance or prediction intervals.

Reference fixture: section8, build 7145701, simulateNetwork / describe. Source 60 s; preparation 30 s; assembly 45 s; test 90 s baseline versus 60 s proposed. Operation durations uniform ±10%. All station capacities 1 and buffers 10. Preparation and assembly share one operator, and test requires one bench. Seeds 42 + 100003*i for i=0…29. No warm-up, failures or scrap. The illustrated 3D workcell is not a literal reproduction of this statistical model.

Three.js 0.160.1, MIT licence, bundled in assets. No music, narration or third-party brand assets are included.
